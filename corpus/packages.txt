# Sentinel coverage corpus — pinned package list
#
# One `name@version` per line. Versions are exact and never floating: a corpus
# that resolves `latest` measures a different population every run, and the
# coverage figure stops being comparable to the one before it.
#
# The artifact digest for each line is recorded in `artifacts.lock.json` on the
# first run and verified on every run after. npm can republish a version under
# the same number; if that happens the run fails rather than quietly measuring a
# different artifact.
#
# These thirteen are the packages Hosted Watch actually monitors, pinned at the
# versions it had recorded on 2026-08-12. They were chosen for release cadence
# rather than as a representative sample of the ecosystem — see corpus/README.md.
#
# The original n=25 corpus behind the published 32% figure was never checked in
# and cannot be reconstructed. This list does not reproduce it and should not be
# compared against it.
